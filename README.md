## About

Interactive, single-page portfolio themed around the **Cyber Kill Chain** —
each section maps to a phase of an investigation, from reconnaissance to
actions on objectives. Built to help recruiters quickly understand my
profile, projects and technical arsenal.

### Highlights

- 🎯 **Kill-chain investigation map** — seven phases, one profile
- 🤖 **AI assistant** — floating chat for recruiters to ask about my background
- 🌍 **Bilingual** — fully available in English and French
- 📄 **CV in both languages** — downloadable PDF, EN / FR
- 💻 **Interactive terminal** — explore my experience via commands
- 📱 **Fully responsive** — desktop, tablet and mobile
